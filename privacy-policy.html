Privacy First Architecture

DeskStacks Privacy Policy

Last updated: October 2026

DeskStacks ("the Application") is an ultra-fast desktop workspace and capsule organizer for macOS, engineered with Zero-Knowledge and 100% On-Device Privacy as core architecture.

1. Zero Data Collection & Tracking

DeskStacks does not collect, track, transmit, or monetize any personal data, usage patterns, device identifiers, or file contents. We maintain no analytics servers and run zero telemetry code.

2. Local File & Capsule Management

All folder indexing, capsule stacking, and file previews happen locally on your Mac using native Apple File System (APFS) APIs. Files never leave your local storage.

3. Zero-Knowledge Protected Vault

Items placed in the protected Vault capsule are encrypted locally using military-grade AES-256-GCM. Keys are secured within your Apple Keychain / Secure Enclave and protected by Touch ID. No external entity can access or decrypt your vault.

4. Apple Sandboxing & Security

DeskStacks complies fully with Apple's macOS App Sandbox security model. It accesses folders strictly through explicit system authorizations.

5. Contact

For questions or privacy inquiries, contact the developer at support@deskstacks.app.
